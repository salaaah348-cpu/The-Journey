Human connection: Bridging the distance

مشروع موشن جرافيك يستعرض رحلة الإنسان التاريخية في قهر المسافات وتطوير وسائل الاتصال من النقوش البدائية والرسائل الورقية إلى الثورة الرقمية الحديثة. يسلط الفيلم الضوء على الشغف الإنساني المستمر بالترابط، مطبقاً تساؤلاً درامياً حول مدى قربنا الحقيقي في عصر الشاشات.
